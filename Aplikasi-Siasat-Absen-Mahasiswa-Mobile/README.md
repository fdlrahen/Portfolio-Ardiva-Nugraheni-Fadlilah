# 📱 SIASAT – Student Attendance Mobile Application

A native Android mobile application developed entirely in **Kotlin (`.kt`)** to support student attendance activities within an academic environment.

This project demonstrates the implementation of an Android application using Kotlin, focusing on mobile application development and the digitalization of student attendance processes.

## 🎯 Project Objectives

- Develop a native Android application using Kotlin.
- Provide a mobile interface for student attendance activities.
- Explore the implementation of academic services on a mobile platform.
- Apply object-oriented programming principles in Android development.

## 🛠️ Technology Stack

- **Programming Language:** Kotlin
- **Platform:** Android
- **Source Files:** Kotlin (`.kt`)
- **Development Environment:** Android Studio

## 🚀 Getting Started

### Prerequisites

- Android Studio
- Android SDK
- Kotlin support enabled in Android Studio

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/fdlrahen/Portfolio-Ardiva-Nugraheni-Fadlilah.git
   ```

2. Open the `Aplikasi-Siasat-Absen-Mahasiswa-Mobile` project directory in Android Studio.

3. Allow Android Studio to synchronize the Gradle project and download the required dependencies.

4. Connect an Android device or start an Android emulator.

5. Build and run the application from Android Studio.

> Note: These instructions assume the repository contains the required Android project configuration files, such as `settings.gradle.kts` or `settings.gradle`, and the appropriate module-level Gradle files.
